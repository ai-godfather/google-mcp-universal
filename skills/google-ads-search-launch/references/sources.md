# Primary guidance

Google's rules change. Reopen the relevant page before each new structural or
policy decision, especially supported asset languages, RSA recommendations,
automated bidding and policies. Keep local pilot decisions clearly separate
from Google's recommendations, and do not treat forums or secondary summaries
as API or policy authority.

| Source | Use |
|---|---|
| [Organize ad groups](https://support.google.com/google-ads/answer/6372655?hl=en) | Campaign settings and budgets versus tightly themed ad groups; no single universal structure |
| [ABCs of account structure](https://support.google.com/google-ads/answer/14752782) | Simplified structure for AI-based Search |
| [Search simplification](https://business.google.com/uk/think/search-and-video/ai-for-search-advertising-campaign-strategy/) | Why to avoid unnecessary fragmentation; not a guaranteed result for a small pilot |
| [Responsive search ads](https://support.google.com/google-ads/answer/7684791?hl=en) | 15/4 assets, 30/90/15 limits, 2+ RSAs per ad group with distinct final URLs |
| [Ad Strength](https://support.google.com/google-ads/answer/9921843?hl=en) | Creative feedback areas and asset recommendations; not serving eligibility |
| [Spending limits](https://support.google.com/google-ads/answer/10486637?hl=en) | Average daily budget versus daily and monthly limits |
| [Business information](https://support.google.com/adspolicy/answer/12499303?hl=en) | Business name and logo requirements |
| [Image assets](https://support.google.com/google-ads/answer/9566341?hl=en) | Eligibility, dimensions and requirements |
| [Price assets languages](https://support.google.com/google-ads/answer/7065415?hl=en) | Languages and currencies supported for price assets |
| [Healthcare and medicines policy](https://support.google.com/adspolicy/answer/176031?hl=en) | Product- and country-specific claims, if the category is health-related |
| [Unapproved substances](https://support.google.com/adspolicy/answer/15595718?hl=en) | Ingredients and categories that cannot be advertised |
| [Ad Preview and Diagnosis](https://support.google.com/google-ads/answer/148778?hl=en) | Checking your own ads without accruing impressions |
| [Auction Insights](https://support.google.com/google-ads/answer/2579754?hl=en) | Competitors in the same auctions, once data is sufficient |
| [Ads Transparency Center](https://adstransparency.google.com/) | Real competitor creatives, advertisers, regions and dates |
| [Google Ads API reference](https://developers.google.com/google-ads/api/reference/rpc) | Field semantics (for example promotion `percent_off`, price offerings) in the current API version |
| [DataForSEO Google Ads search volume](https://docs.dataforseo.com/v3/keywords_data-google_ads-search_volume-live/) | Optional provider: CPC currency and rate limits |
| [DataForSEO errors](https://docs.dataforseo.com/v3/appendix/errors/) | Optional provider: empty results versus credit, throttling and outage errors |

Business performance is judged from complete actual spend, qualified
conversions and margins with correct attribution and currency. No structure,
copy or Ad Strength score guarantees it.
